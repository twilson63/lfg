LFG skill repository

planned Publish a standalone, publicly installable twilson63/lfg GitHub repository whose root skill is discoverable by the Skills CLI and therefore eligible for skills.sh telemetry-based listing.

Definition

In this project, LFG is a portable procedural skill that directs coding agents through bounded research, explicit acceptance criteria, file-based coordination, validation, and independent review. It is not an autonomous implementation framework, a package, or a promise of a skills.sh ranking.

Research evidence

  • Existing source: lfg-skill-v3-extracted.md and installed canonical LFG skill.
  • skills.sh docs and FAQ (2026-06-06): skills are GitHub-hosted repositories with a skill definition file and README; anonymous npx skills add <owner/repo> telemetry makes installed skills appear on the leaderboard.
  • Official CLI help v1.5.20: a root SKILL.md is a supported discovery layout; root discovery is preferred unless --full-depth is specified.

Goals

  • Expose exactly one root-level SKILL.md named lfg.
  • Provide clear installation and usage documentation for Skills CLI and common agent skill directories.
  • Include repository hygiene, security disclosure guidance, a no-dependency validator, and CI.
  • Create and push a public repository under twilson63.

Non-goals

  • Guarantee immediate listing, a topic classification, audit, or ranking on skills.sh.
  • Publish secrets, local ZenBin identity files, or unrelated workspace research artifacts.
  • Ship executable agent code or claim compatibility with every agent runtime.

Constraints

  • Use standard, portable Markdown and YAML frontmatter.
  • Keep the canonical skill at repository root to avoid ambiguous multi-skill discovery.
  • Repository must be public for ordinary GitHub installation and inspection.
  • No third-party CI actions or runtime dependencies; never commit .zenbin/.

Judge rubric

Correctness, acceptance coverage, security/privacy, simplicity, maintainability, validation, taste, and originality. Taste/originality must score at least 4/5: direct, practical docs rather than generic agent-skill boilerplate.

Definition of done

  • All five steps pass with recorded evidence.
  • The repository is public and installable with the stated Skills CLI command.
  • The README accurately states that skills.sh listing follows anonymous installation telemetry rather than a manual submission.
